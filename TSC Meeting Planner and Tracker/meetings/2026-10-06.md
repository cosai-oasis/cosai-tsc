## 4. CoSAI Week in Review

> A summary of what was discussed across CoSAI Workstreams and SIGs
> since the last TSC meeting. Sourced from meeting minutes files dated
> within the last 14 days. Groups that did not meet are noted explicitly.

| Group | Last Met | Summary |
|---|---|---|
| WS1 — Software Supply Chain Security for AI Systems | Did not meet | Did not meet |
| WS2 — Preparing Defenders for a Changing Cybersecurity Landscape | 2026-09-22 | The group reviewed the telemetry paper and discussed scope reduction to focus initial publication on OCSF and OpenTelemetry. Josiah Hagen introduced two Duke University student collaboration projects — a graph MCP server acting as a CoSAI oracle and a testable risk-map harness — both pending TSC approval. The group also discussed jailbreak scoping using capability consequence levels and planned to rescope the zero trust paper once a new version of the CoSAI risk map is available. A scoping statement for AI telemetry security is being drafted for TSC approval. |
| Telemetry SIG — AI Security Telemetry (WS2) | 2026-10-01 | The group made progress refactoring the main telemetry paper, condensing the narrative to approximately 10 pages with separate addenda for attack inventories and cross-mappings. Rithikha Rajamohan presented the Trustgraph Telemetry subgroup's overlap map with WS2. The group aligned that AI security metrics should be available in both OCSF and OpenTelemetry, and that telemetry standards must be anchored by an attack corpus. Josiah Hagen noted that proposing new tools requires TSC endorsement due to maintenance and supply chain concerns. Several OCSF pull requests are awaiting final approvals. |
| WS3 — AI Security Risk Governance | Did not meet | Did not meet |
| WS3 Threat Modeling — Agentic Coding Threat Modeling (WS3) | 2026-10-02 | Kevin Calloway reported that the agentic coding group showed strong interest in the threat modeling high-level design. The group is deferring a decision between a broad ADLC threat model and a focused red-teaming approach pending a leadership meeting to be scheduled with David LaBianca, Shrey Bagga, and others. Navneet Keshav added approximately 18 review comments to the threat model document, including new tampering threats and unmapped controls, which the team plans to address in a collaborative working session. |
| CoSAI-RM SIG — Coalition for Secure AI Risk Map | 2026-09-30 | David LaBianca presented a structural revision to the control corpus, splitting descriptions from implementation guidance in a separate preview branch. The group agreed to restrict the initial corpus landing to MCP version 1, with version 2 updates handled as a follow-on branch. Risk mappings for agent identity spoofing and shadow agents were reviewed, with the clarification that risk-to-control mapping implies partial rather than full mitigation. The next threat model direction — potentially focused on agent red-teaming workflows — was deferred for a dedicated group discussion. |
| Code SIG — Security of AI-Assisted Code Generation | 2026-09-29 | The group outlined a transition plan from legacy rule files to a skills-based framework for Code Guard 2.0, with version 1.5 maintained on a separate branch for legacy support. Topics included migration documentation, platform compatibility verification, event-driven integration patterns (MCP, mini DAGs, webhooks), and a proposed skill attestation roadmap. Cisco's team noted they have custom rules that will require porting to the new framework. |
| WS4 — Secure Design Patterns for Agentic Systems | 2026-10-01 | The containment paper remains on schedule with the abstract and conclusion still to be finalized, targeting early TSC reviewer review around October 15. The multimodal threat taxonomy team was advised to convert their Google Doc to Markdown and submit a PR. Cross-workstream alignment gaps between agent credentials, trust graph, and telemetry were flagged as needing consensus before finalizing integration approaches. OASIS emphasized all CoSAI working meetings must be scheduled through OASIS for official records. RSAC 2027 talk proposals are being collected ahead of the October 8 cutoff. |
| ADLC SIG — Security of Agent Development Lifecycle | 2026-09-30 | The group discussed threat model scope, including sensitivity protection cascading from jurisdiction to sensitivity levels and Kevin Calloway's threat model for the code review stage. Bill Stout raised the question of integrating MLOps/CrispML methodologies for non-deterministic applications. Emrick Donadei reported the decommissioning RFC is nearing final form, PR 43 adds a behavioral monitoring control to the risk map, and Courtenay is updating the ADLC definitional paper in PR 197. |
| Agent Credentials Group | 2026-10-01 | The group agreed to reduce the 56-page draft to approximately 16 pages of main text and 10 pages of appendix, and to host the document as Markdown files in a new GitHub repository under the CoSAI group. Benedict Lau is to contact Claudia to request the repository. The group aligned on defining a credential as an attestation result that has passed through a verifier, while deferring the classification of attribute assertions for further discussion. A first draft is targeted for internal review before public publishing. |
| Multimodal Agentic Security — Multimodal Threat Taxonomy (WS4) | 2026-10-02 | The group agreed to retain the current taxonomy core and defer cross-modal structural expansions to future iterations, incorporating complex cross-modal examples as illustrations. A phased roadmap was established: taxonomy first, then threat modeling in version 2. Shriti Priya submitted an RSAC 2027 speaking proposal and is preparing a 5–6 slide presentation for the WS4 meeting on October 8. The group is coordinating with Claudia to resolve Google Doc export restrictions and convert the document to Markdown for a PR. |
| Trust Graph — Agent Trust Graph (WS4) | 2026-09-24 | The group discussed a roughly 75% content overlap with the WS2 telemetry group and explored whether to consolidate or form a WS2 subgroup. Benedict Lau and Rithikha Rajamohan planned a 5–8 slide presentation for the WS2 group to align efforts, using Claude to synthesize Miro board content. Core focus areas are agent telemetry and delegation records. A final structural decision on integration with WS2 was deferred pending Parul's availability. |

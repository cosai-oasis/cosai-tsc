## 4. CoSAI Week in Review

> A summary of what was discussed across CoSAI Workstreams and SIGs
> since the last TSC meeting. Sourced from meeting minutes files dated
> within the last 14 days. Groups that did not meet are noted explicitly.

| Group | Last Met | Summary |
|---|---|---|
| WS1 — Software Supply Chain Security for AI Systems | 2026-10-14 | The group adjusted its meeting cadence to bi-weekly and adopted GitHub as the central plan of record for tracking work items. A key TSC-relevant decision was reached to propose renaming the workstream from "Software Supply Chain Security for AI Systems" to "AI Supply Chain" to better reflect its full scope including hardware. The group also discussed auditing legacy RFCs, establishing a formal vetting process for new proposals, and coordinating with external bodies such as OpenSSF and the AI Infrastructure Foundation to avoid duplication. |
| WS2 — Preparing Defenders for a Changing Cybersecurity Landscape | 2026-10-06 | The group reviewed CoSAI's zero trust publication and the status of the telemetry workstream's first deliverable. Two proposed collaboration projects with Duke University (an RDF/OWL risk map representation and a testable risk map harness) were discussed pending TSC consensus call, which subsequently passed. An Apache-style incubation model was proposed for prototype projects. The group also discussed OCSF and OpenTelemetry alignment and RSA Conference submissions. |
| Telemetry SIG — AI Security Telemetry (WS2) | 2026-10-15 | The group reviewed version 6 of the telemetry paper, now structured into main paper, attack detection addendum, and cross-mapping addendum. The group aligned on treating the paper as essentially complete at the 95% milestone and preparing to submit it to the TSC. TSC-relevant: the paper is approaching submission readiness. The group also discussed enterprise deception technologies, critical infrastructure deployment profiles, OCSF/OTEL standards integration, and advanced topics including decision models and world models. |
| WS3 — AI Security Risk Governance | Did not meet | Did not meet |
| WS3 Threat Modeling — Agentic Coding Threat Modeling (WS3) | 2026-10-16 | The group worked on the threat modeling paper for security review agents, discussing AI code review routing heuristics, tandem AI-and-human review approaches for high-risk code, multi-model validation strategies, and CI/CD pipeline security. The group agreed to incorporate misaligned AI agents as threat actors and accepted whole-repository cumulative change checks as a detective control. This paper is tracked as a pending TSC presentation (Issue #123). |
| CoSAI-RM SIG — Coalition for Secure AI Risk Map | 2026-10-14 | The group continued reviewing MCP security paper-derived risks and controls, focusing on credential risk exposure and broadening its scope to cover all integration hubs rather than agents exclusively. The Maestro framework was proposed as an external framework mapping option (pending a formal issue submission). Version 2 of the shared responsibility framework integration was raised as a follow-on discussion item with David LaBianca. |
| Code SIG — Security of AI-Assisted Code Generation | 2026-10-13 | The group reviewed benchmark evaluation results for Code Guard across 121 Python tasks on multiple models, analyzing LLM cost and security trade-offs. A proposal to add the Meta Cyber Security benchmark for multi-language testing was discussed pending Slack feedback. The group also discussed RSA Conference submissions and coordinating with the marketing committee for project outreach, with Claudia Rauch (OASIS) facilitating an introduction to marketing committee leads. |
| WS4 — Secure Design Patterns for Agentic Systems | 2026-10-15 | The group covered RSA Conference talk submissions, and received updates on the containment paper (ready for end-to-end review before TSC submission), agent credentials paper (condensed to ~20 pages, targeting TSC review by end of October), multimodal taxonomy conversion to markdown, and the Otus specification refactoring into three independent specs (passport, bridge, router). The Trust Graph group's future disposition remains unresolved, with potential merger into WS2 discussed but no decision made. Claudia Rauch was asked to investigate contribution procedures for submitting the multimodal taxonomy to NIST or MITRE. |
| ADLC SIG — Security of Agent Development Lifecycle | 2026-10-14 | The group discussed the definitional paper with a section review deadline of approximately October 20–22. An RFC was handed off to the Telemetry SIG for review. The group agreed that every agent must have a named individual human owner, and addressed agent decommissioning as a data retention question. Remaining paper sections (5, 6, 7) were assigned to Bill Stout. Readability of LLM-generated text was flagged as a concern requiring human editing. |
| Agent Credentials Group | 2026-10-15 | The group published the main text of the agent credentials paper for internal WS4 review, targeting TSC submission by end of October following a two-week review period. A 10-slide presentation was drafted for the next working group call, with the slot extended to 30 minutes. The group aligned on proceeding with version 1 publication without waiting for vendor consensus, and agreed that contributor names require explicit consent before inclusion. TSC-relevant: TSC submission is targeted for the end of October. |
| Multimodal Agentic Security — Multimodal Threat Taxonomy (WS4) | 2026-10-12 | The group discussed the value proposition of the multimodal threat taxonomy relative to existing frameworks (MITRE ATLAS, STRIDE, NIST AI), which lack modality-specific mechanism coverage. The group aligned on publishing the taxonomy as a CoSAI white paper first before pursuing MITRE ATLAS contributions. Navneet Keshav's agentic threat modeling workflow at Lenovo was agreed upon as a real-world case study for the paper. The taxonomy document is being converted to markdown for pull request review. |
| Trust Graph — Agent Trust Graph (WS4) | Did not meet | Did not meet — per WS4 minutes, regular Trust Graph meetings have lapsed due to low attendance; future disposition (close out, independent deliverable, or merge into WS2) remains under discussion. |

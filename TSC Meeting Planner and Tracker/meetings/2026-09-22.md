## 4. CoSAI Week in Review

> A summary of what was discussed across CoSAI Workstreams and SIGs
> since the last TSC meeting. Sourced from meeting minutes files dated
> within the last 14 days. Groups that did not meet are noted explicitly.

| Group | Last Met | Summary |
|---|---|---|
| WS1 — Software Supply Chain Security for AI Systems | Did not meet | Did not meet |
| WS2 — Preparing Defenders for a Changing Cybersecurity Landscape | Did not meet | Did not meet |
| Telemetry SIG — AI Security Telemetry (WS2) | 2026-09-17 | The SIG welcomed new participants including a Cisco security engineer with a background in AI security and OCSF collaboration. Arthur Saputkin confirmed the CoSAI AI telemetry paper is currently under review by the TSC, with feedback expected imminently. Jeff Leva reported active OCSF pull requests introducing an AI status realm and stop reason, and noted OCSF maintainer bandwidth constraints are being addressed partly by leveraging Cisco representatives. The group decided to exclude trust graph contributions from the current paper draft due to the initiative's early stage, and noted that OCSF/OpenTelemetry joint meetings are resuming — directly relevant to TSC as the paper's external use with OCSF and OpenTelemetry depends on completing co-chair review (#67). |
| WS3 — AI Security Risk Governance | Did not meet | Did not meet |
| WS4 — Secure Design Patterns for Agentic Systems | 2026-09-17 | The meeting covered a proposal from NVIDIA's Laura Seletos for a standardized, vendor-agnostic security patterns framework providing prescriptive guidance, threat models, and reusable architectural artifacts for AI workloads, intended to evolve into infrastructure-as-code hosted in a CoSAI GitHub library. Jeff Leva reported the containment paper is progressing with multiple pull requests submitted across sections. Matthew Gladney presented the ODIS working group's decision to structure the framework into three layers — bridge, passport, and router — to be broken down asynchronously via GitHub issues. Rithikha Rajamohan noted the agent credentials group is targeting a first rough draft. Ian Molloy flagged lingering challenges around internal consistency across deliverables and securing volunteers for risk mapping — a concern relevant to the TSC. |
| CoSAI-RM SIG — Coalition for Secure AI Risk Map | 2026-09-16 | The SIG focused on WS4 risks and controls feedback, repository branch management, and framework updates. David LaBianca reported good initial feedback on observability, isolation/containment, and authorization controls from WS4, though decommissioning lifecycle reviews remain paused. Phase 3 agent evals for Persona Critic and Persona Creator are expected to land shortly. Plans are underway to update Atlas to v6, add NIST AI RMF, Etsy, and ISO 4201 mappings, and perform a develop-to-main merge to resolve branch divergence. Shrey Bagga reported creating a draft GitHub issue covering CoSAI-RM and all three WS3 SIGs for an upcoming TSC presentation, which is directly relevant to the TSC. |
| Code SIG — Security of AI-Assisted Code Generation | 2026-09-15 | The SIG reviewed pull request updates, a security fix for the MCP server Docker configuration, and ongoing Code Guard skill modernization to align with current skill standards rather than retrofitted rules. Thomas Bartlett demonstrated benchmark results using Inspect AI and a Notre Dame security evaluation harness. The group agreed to initially publish final benchmark results (including token usage and cost data) and consult the TSC before releasing full model traces — a direct TSC touchpoint. The SIG also discussed plans to create a GitHub issue to track future research paper publication. |
| ADLC SIG — Security of Agent Development Lifecycle | 2026-09-16 | The SIG formalized new leadership with Courtenay Ngo (Microsoft) and Matthew Gladney replacing Parul as co-leads. Sarah Novotny's initial definitional paper distinguishing the AI Development Lifecycle from the SDLC was opened for group review via PR 197, with a two-week deadline for comments. The group agreed to incorporate the older scope document into the definitional paper and retire it. A recurring 15-minute research presentation slot was established, with a Slack sign-up table to be created. The decommissioning lifecycle RFC 170 is being prepared as a clean draft for next-meeting review, and observability RFC 175 was closed as redundant given existing risk map coverage. |
| Agent Credentials Group | 2026-09-17 | The group refined the white paper's scope and target audience, establishing a target length of under 20 pages aimed at identity practitioners designing gateways, with vendor implementation appendices possible. The group agreed to maintain the white paper and baseline profile artifacts in a GitHub repository to facilitate continuous updates and external contributions — a living document approach. A traffic-light system (red/yellow/green) was adopted to track section readiness. Section ownership and a comprehensive review workflow were established, with a broad CoSAI review planned for October. The group continues to coordinate alignment with the ODIS passport layer and the WS2 telemetry workstream to prevent standard fragmentation. |
